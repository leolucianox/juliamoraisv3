# Julia Morais — Tatuagens Fine Line

Site em portfólio para Julia Morais, tatuadora fictícia especializada em fine line e tatuagens delicadas, em São Paulo.

Construído com [Next.js](https://nextjs.org) (App Router), [Tailwind CSS](https://tailwindcss.com) e [Framer Motion](https://www.framer.com/motion/).

## Páginas

- `/` — Home: apresentação, prévia de trabalhos, atendimento e contato
- `/sobre` — história e estilo da tatuadora
- `/trabalhos` — galeria completa de trabalhos por estilo
- `/contato` — formulário de contato integrado ao WhatsApp

## Rodando localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Build de produção

```bash
npm run build
npm run start
```
